DOM-based XSS Vulnerable

A small search-preview widget, like the live suggestions under a real search box. It reads the typed text (or the q URL parameter) in the browser and assigns it directly to .innerHTML, so the browser parses it as markup. A plain <script> tag will not fire here — browsers do not execute <script> elements inserted via .innerHTML — but an event-handler attribute such as onerror does.

Input / Source
The preview box, or the q URL parameter
Unsafe sink
element.innerHTML = value;
Fix
Assign to .textContent instead of .innerHTML
